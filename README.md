# docs.mhmproductions.com

GitHub Pages **user site** for the `mhmproductions` account. Its custom domain is
`docs.mhmproductions.com`, so every public project-site repo on this account that
has no custom domain of its own is served at:

    https://docs.mhmproductions.com/<repo-name>/

| Path | Repo | Source |
|---|---|---|
| `/travel-wrangell-runbook/` | `travel-wrangell-runbook` | generated by `tools/publish-runbook.py` in the private `travel-wrangell` repo |

`robots.txt` here (Disallow: /) keeps the whole domain out of search. The root page is
deliberately bare and links to nothing; client docs are reached by the link they were sent.

**Adding another client's docs:** create a public repo, enable Pages on `main`, and do
NOT add a CNAME file. It appears at `/<repo-name>/` automatically.

DNS (mhmproductions.com, Squarespace Domains): `CNAME docs -> mhmproductions.github.io`
